Import healthcare facilities

The map reads records directly from Neon. Browser uploads are temporarily disabled on static hosting until the administrator login and database write permissions are configured. No database owner password or import token should be entered into a static website.

Import records securely now

From a trusted computer with the repository checked out, set the private DATABASE_URL environment variable and use the existing command-line importer:

npm run import:facilities -- /path/to/facilities.csv --dry-run
npm run import:facilities -- /path/to/facilities.csv

CSV and JSON records are validated before import; matching source IDs update existing records. Keep connection strings out of GitHub and the website.
